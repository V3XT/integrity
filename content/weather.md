Tracking weather can help set the scene and create interesting and unexpected scenarios. Poor weather can often make challenges harder, and can cause plans to change.


# Hex Flower Weather

This is a simple system for tracking what the weather is. It uses guided randomness to create a system that's not completely random, but isn't completely predictable either.
